الخدمات الأساسية

كل خدمة موصوفة مع صور حقيقية توضح طبيعة العمل الميداني بدقة.

تركيب تكييفات

تركيب المكيف وتثبيت الوحدات وتجهيز التوصيلات والصرف وتشغيل الجهاز بعد التركيب.

صيانة التكييف

فحص الأعطال الشائعة مثل ضعف التبريد، توقف الجهاز، تسريب المياه أو الأصوات غير الطبيعية.

تنظيف التكييف

تنظيف الفلاتر والوحدة الداخلية والخارجية حسب حالة الجهاز لتحسين تدفق الهواء.

أعمال كهرباء

فحص الأعطال الكهربائية والتوصيلات والمفاتيح والقواطع المرتبطة بالأجهزة والمكيفات.

فحص الأعطال

إذا كان سبب المشكلة غير واضح، يتم فحص الجهاز أو التوصيلة وتحديد السبب قبل تنفيذ الخدمة.

خدمة داخل الرياض

تواصل وحدد الحي ونوع الخدمة للتأكد من توفر الزيارة في موقعك.

مشاكل شائعة

ما المشكلة الموجودة عندك؟

اختر أقرب وصف للمشكلة ثم تواصل مباشرة.

التكييف لا يبردالجهاز يعمل لكن التبريد ضعيف أو الهواء غير بارد.
تسريب مياهنزول مياه من الوحدة الداخلية أو مشكلة في الصرف.
التكييف لا يعملالجهاز لا يبدأ التشغيل أو يفصل بعد وقت قصير.
صوت أو اهتزازصوت جديد أو مرتفع أثناء تشغيل المكيف.
قاطع يفصلمشكلة كهرباء أو تحميل أو توصيلة تحتاج فحص.
تركيب جهاز جديدتجهيز وتركيب مكيف جديد أو نقل جهاز لموقع آخر.
