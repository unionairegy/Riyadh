تركيب تكييفات

تركيب المكيف وتثبيت الوحدات وتجهيز التوصيلات والصرف وتشغيل الجهاز بعد التركيب.

صيانة التكييف

فحص الأعطال الشائعة مثل ضعف التبريد، توقف الجهاز، تسريب المياه أو الأصوات غير الطبيعية.

أعمال كهرباء

فحص الأعطال الكهربائية والتوصيلات والمفاتيح والقواطع المرتبطة بالأجهزة والمكيفات.

تنظيف التكييف

تنظيف الفلاتر والوحدة الداخلية والخارجية حسب حالة الجهاز لتحسين تدفق الهواء.

فحص الأعطال

إذا كان سبب المشكلة غير واضح، يتم فحص الجهاز أو التوصيلة وتحديد السبب قبل تنفيذ الخدمة.

خدمات الكهرباء داخل الرياض

تركيبات جديدة وكشف أعطال الكهرباء والقواطع والمفاتيح والبرايز والإنارة داخل الرياض.

تأسيس وتركيب كهرباء

تجهيز وتركيب نقاط الكهرباء والتوصيلات الجديدة حسب احتياج الموقع.

تركيب مفاتيح وبرايز

تركيب واستبدال المفاتيح والبرايز التالفة أو إضافة نقاط جديدة.

لوحات وقواطع

فحص القواطع واللوحات عند الفصل المتكرر أو وجود مشكلة في أحد الخطوط.

تركيب وصيانة الإنارة

تركيب وحدات الإنارة واستبدال التالف وفحص نقاط الإضاءة التي لا تعمل.

كشف أعطال الكهرباء

فحص الأعطال غير الواضحة مثل انقطاع نقطة، ضعف توصيل أو فصل مفاجئ.

فصل القاطع والأحمال

فحص سبب فصل القاطع بشكل متكرر وتحديد ما إذا كانت المشكلة من حمل أو توصيل.

عندك مشكلة كهرباء ومش عارف سببها؟ أرسل وصف المشكلة واسم الحي على واتساب أو اتصل مباشرة.
